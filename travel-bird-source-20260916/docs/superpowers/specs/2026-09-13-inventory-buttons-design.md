# 第一部分：库存素材与按钮视觉统一设计

## 范围

本阶段只处理库存素材展示的一致性、主要按钮视觉统一，以及确认明信片不再维护独立语言入口。保留现有 React + TypeScript + Vite 架构、item ID、存档结构、旅行算法、奖励机制、小鸟状态机、庭院布局和室内背景。

## 方案

新增轻量 `BirdButton` 组件，提供 `primary`、`secondary`、`small`、`danger` 四种外观变体，并通过 `:active`、`:disabled` 和 `:focus-visible` 表达按压、禁用和键盘焦点状态。组件不持有业务状态，仅透传原生 button 属性和 className。

主要面板中的文字按钮统一使用该组件；场景热点和 icon-only 控件保持原有交互，只共享必要的颜色/焦点规则。按钮样式使用现有纸张/水彩色板，不添加渐变玻璃、发光或复杂动画。

库存与种子/作物/食物缩略图继续复用现有资源，通过统一资源映射、透明安全边距和固定展示容器减少类别差异。不修改任何物品 ID 或业务数据。

明信片组件保持全局 `language` 输入，只提供正面/背面翻面操作；不新增、保留或读取明信片内部的语言切换状态。

## 验收

- 主要面板文字按钮使用统一 BirdButton 语言，并保留原点击行为。
- 库存中种子、作物、食物缩略图使用统一尺寸和显示方式。
- 明信片 DOM 中不存在中文/English 语言切换入口。
- 既有测试、TypeScript 检查和 Vite build 通过。
- 不改动旅行、奖励、小鸟、庭院、存档和全局语言逻辑。
