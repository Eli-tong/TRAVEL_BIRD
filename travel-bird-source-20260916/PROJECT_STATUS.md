# 项目状态

更新时间：2026-09-10

本次改版保留了原有 v1 本地存档、种植→收获→烹饪→装包→旅行→明信片与奖励循环，并将入口改为温暖的树屋室内与相连的室外菜地。主角是同一只蓝色和尚鹦鹉，平静、高兴、打盹、生气由互动自然触发；状态计时器在旅行、隐藏页面、场景切换和卸载时正确处理。

素材位于 `public/art/`，原始 AI 位图与可重复的裁切压缩脚本位于 `assets/source/`、`scripts/prepare-assets.mjs`。室内、室外、柜子、鸟的四态、独立地块/作物/食物/行囊及九张明信片均已分层接入；场景中没有固定背景鸟。正式素材使用 WebP，运行时预加载关键图。

Netlify 配置在 `netlify.toml`，发布目录为 `dist`；`public/_redirects` 和同等 TOML 回退规则支持静态托管下的 SPA 刷新。当前代码未使用 React Router，因此没有额外路由依赖。
