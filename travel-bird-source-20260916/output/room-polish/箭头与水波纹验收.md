# 旅行小鸟：出口箭头与场景水波纹验收

日期：2026-09-12

## 本轮修改

- 出口沿用现有手绘素材 `public/art/room-v2/exit-arrow.png`，未重画背景。出口热点从统一 941×1672 场景坐标重新定位为中心 `(615,1490)`，落在最底部浅色木板的视觉中心附近；箭头保持原有指向，显示宽度由 58px 调整为 76px，高度保持 52px。
- 出口普通画面只显示自然箭头图案，移除文字、矩形底板和白色框；点击仍只打开“庭院准备中”提示，不进入旧庭院。
- 在 `src/ui/RoomScene.tsx` 的统一场景容器增加单一 `onPointerDown` 反馈。鼠标、触摸和触控笔都由 Pointer Events 进入同一处理；按容器实际 `getBoundingClientRect()` 换算为百分比坐标，因此 contain 缩放和不同视口不会偏移。反馈由暖白中心光点与浅金扩散环组成，约 560ms 淡出，层本身不接收点击；弹窗阻塞时不再生成。`prefers-reduced-motion` 下缩短为 140ms。
- 鸟、背包、厨房、柜子和出口的原有业务回调、存档和庭院接口未改变；一个物理点击只生成一个水波纹，键盘操作继续使用 focus-visible，不伪造鼠标坐标。

## 浏览器实测

`outputs/polish/arrow-ripple-checks.json` 记录了 Chromium 实测结果：

- 390×844、320×568、1440×1000 均通过。
- 箭头中心与统一坐标 `(615,1490)` 对齐，宽度实测 76px，无横向溢出。
- 空白区域和热点点击都只生成一次水波纹，反馈层 `pointer-events: none`。
- 打开出口、料理台、行囊和小鸟面板后，场景不会穿透产生反馈；出口仍停留在“庭院准备中”。
