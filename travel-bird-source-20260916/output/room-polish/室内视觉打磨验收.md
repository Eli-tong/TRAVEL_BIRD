# 旅行小鸟｜新版室内视觉与点击反馈打磨

日期：2026-09-12。此次只调整新版室内的入口视觉、文字和点击反馈；房间构图、素材位置、统一 941×1672 坐标、已有功能、存档和旧庭院均保留。

## 已完成

- 移除左上常驻“林间小屋”标题；鸟名仍来自现有状态并保留在设置／互动中。
- 门口背景本身已有可辨认的下方木质通道，因此没有重画房间；移除“门口”文字矩形，加入一枚手绘木质方向箭头。点击仍只打开提示：`外面的小路还在准备中，过些时候再去看看吧。`
- 将右上文字菜单改为手绘羽毛图标。可访问名称仍为“打开菜单”，点击、Escape 和焦点恢复沿用现有菜单弹窗。
- 删除普通游玩时的热点 active 矩形底色和内框；厨房、柜子、门口点击直接打开对应面板。相关场景控件保留透明触摸高亮关闭；键盘 `focus-visible` 使用暖棕色 2px 细线。
- 小鸟与背包使用 Web Animations 做一次性微缩放，连续点击取消上一动画，接触锚点不漂移；`prefers-reduced-motion: reduce` 时不播放。静态家具不缩放。
- 弹窗文字统一暖深棕、常规圆润系统字体栈和更清晰层级，没有引入外部字体服务。
